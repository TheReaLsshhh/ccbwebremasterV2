# Reporting website security concerns

The public reporting entry point is `https://ccbacad.dpdns.org/.well-known/security.txt`.
It directs reports to the college Contact page. A maintained reporting route must be
monitored by the institution; creating this document does not establish a response SLA.

Include the affected public URL, a minimal description, the date observed, and a way
to contact you. Do not include credentials, student records, or other people's data.
Do not post sensitive vulnerability details in public issues or comments.

A reporting channel is not authorization to scan, exploit, bypass access controls,
interrupt services, or access private records. No bug bounty or blanket safe-harbor
promise is established here. Request written authorization before active testing.

Maintainers should restrict access to reports, preserve only necessary evidence,
assess impact, remediate, and coordinate any legally required notification with the
college's privacy/security officers. No incident-response or legal-compliance outcome
is guaranteed by this repository.

For the implementation review and outstanding owner actions, see
[`docs/security-and-rights-review.md`](docs/security-and-rights-review.md).
