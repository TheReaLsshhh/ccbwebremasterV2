# Third-party software and content rights

This repository is **not** being declared copyright-free, public domain, or licensed
as a whole under any particular open-source license. AI-assisted development does
not clear third-party rights. The college must verify ownership, permissions, and
applicable legal exceptions before publishing each asset.

upstream licenses; deployment and redistribution must preserve applicable notices.
This is an inventory of verified frontend references, not a complete legal audit of
every dependency or uploaded asset.

## Content rights register requiring institutional verification

| Material | Current evidence | Required action |
| --- | --- | --- |
| College seals and branding | Existing project assets; ownership/authorization documents not provided | Confirm authorized use and any brand restrictions. |
| Bundled campus photos and welcome graphics | Existing project assets; photographer permissions not provided | Record source, rights holder, permitted uses, and any attribution obligations. |
| Responsive WebP derivatives | Generated from existing photos | Derivatives retain the original's rights restrictions; format conversion does not clear copyright. |
| News and slideshow uploads | Supplied through Admin | Obtain publication/reuse rights and any necessary image/privacy permissions; do not assume a social-media post is licensed for reuse. |
| Faculty portraits and biographies | Supplied through Admin | Confirm publication authority and applicable privacy notices. |
| Downloadable documents | Supplied through Admin | Check author/source, permitted distribution, personal-data exposure, and whether a current official version should replace an older copy. |

Store permission evidence in an access-controlled institutional register, not in a
public repository if it contains personal or confidential information. An asset
without an identified reuse basis must be reviewed, replaced, or withheld; a footer
disclaimer does not create permission.
